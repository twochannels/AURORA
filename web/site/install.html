Installing any custom firmware on the FM-1 is at your own risk. If anything goes wrong, the rescue is always there: hold OCT− while switching the FM-1 on and it starts in a USB update mode from which any installer, this one included, works again.

What you need

  • Chrome or Edge on a computer. The page talks to the FM-1 over Web MIDI, which Safari and Firefox do not offer.
  • A USB data cable (some charging cables carry no data) and the FM-1 switched on.
  • No other program using the FM-1's MIDI port: close your DAW, and close the emulator tab if you had the FM-1 selected there.
  • The browser will ask to allow MIDI with system exclusive messages. Say yes; that is how the update travels.

Install

Plug the FM-1 in, switch it on, then press the button and leave the cable alone until the page says it is done. The FM-1 checks the package, restarts into its update mode, writes the firmware (about a minute), and restarts again running AURORA. Your user presets stay where they were, unless the release notes say the sound format changed, in which case the bank starts empty once.

Waiting.

If it stops

  • "FM-1 not found": check the cable, that nothing else holds the port, and that you allowed MIDI when asked. Reload the page and try again.
  • It stopped while writing: the FM-1 stays in update mode until the write is complete. Replug the cable and press Install again; the page notices the update mode and finishes the write.
  • It does not come back: switch it off and on. If it then shows nothing, hold OCT− while switching on and install again.

Going back, or on to another firmware

Install the next firmware the way you installed this one: from the FM-1 Firmware Hub, from that firmware's own installer, or with M-VAVE's updater. AURORA accepts a package that brings Felucca's update loader, which nearly every custom firmware does, and one that brings M-VAVE's own, which the official V15 and firmwares built on it do. The hub's "Back to official V15" works from AURORA 0.3.2 on; before that, AURORA refused the official package on any unit whose first 16 KB of flash were older than V15's, and the screen only flickered. If AURORA refuses a package now, the screen says why for three seconds.

The command-line route still works too: python3 tools/fm1_install.py aurora.fwsc from the source tree, with Python 3, mido and python-rtmidi.
