You need

  • Chrome or Edge, for Web MIDI.
  • A USB data cable, the FM-1 on, and nothing else using its MIDI port: close your DAW and the emulator.
  • To say yes when the browser asks to allow MIDI with system exclusive.

Press the button and leave the cable alone. The FM-1 restarts into its update mode, writes the firmware in about a minute, and restarts running AURORA.

If it stops

  • FM-1 not found: cable, port, permission. Reload and try again.
  • Stopped while writing: replug and press Install again; it finishes the write.
  • Does not come back: switch it off and on. Still nothing: hold OCT− while switching on, then install again. That rescue is always there.

Going back

Any other firmware installs over AURORA the same way, from the FM-1 Firmware Hub or its own installer. From the command line: python3 tools/fm1_install.py aurora.fwsc.
